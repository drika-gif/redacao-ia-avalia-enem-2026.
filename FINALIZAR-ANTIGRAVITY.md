# Atualizar o projeto no Antigravity

O aplicativo já está publicado em https://redacao-ia-avalia-enem-2026.vercel.app/.
Repositório: https://github.com/drika-gif/redacao-ia-avalia-enem-2026.

Abra a pasta desse projeto no Antigravity e envie ao agente:

```text
Atualize esta cópia local com a branch main do repositório
drika-gif/redacao-ia-avalia-enem-2026. antes de fazer novas alterações.

Primeiro confira git status e preserve qualquer alteração local.
Se estiver limpo e na main, use git pull --ff-only.
Se houver alterações, outra branch ou divergência, mostre a situação
e preserve o trabalho antes de integrar. Não use reset --hard.

Leia README.md e FINALIZAR-ANTIGRAVITY.md. Instale as dependências
se necessário e execute npm test e npm run build.

Use o projeto existente na Vercel. As variáveis de produção são
VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, GEMINI_API_KEY e GEMINI_MODEL.
Confira somente a presença das variáveis, sem exibir seus valores.
GEMINI_API_KEY deve permanecer apenas no backend.

Valide cadastro de uma nova professora, confirmação de e-mail,
recuperação de senha e telas no celular. Registre o que foi efetivamente
testado e qualquer pendência. O servidor Vite sozinho não executa /api/ai.

Se houver correções necessárias, teste-as e publique somente no projeto
existente, preservando o endereço e os dados das professoras.
```
